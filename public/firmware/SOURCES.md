# Athena firmware corresponding source

Preview releases: Athena75 display-r4 and Athena1800 screen-r2.

The complete source archive, including the pinned QMK tree, library submodules,
model-specific modifications, build instructions and licenses, is available at:

https://github.com/kbdfans/athena-studio/releases/tag/firmware-preview-20261111

A source mirror is also available at:
https://kbd.cool/studio/firmware/athena-firmware-source-20261111.tar.gz

The SHA-256 hash is recorded in each release's `source.sha256` in releases.json.
Both firmware binaries have been reproduced byte-for-byte with Arm GNU 13.2.rel1.
GPL-2.0-only applies to the project additions; existing upstream file licenses and
Inter's SIL OFL-1.1 are preserved. No user backups or keyboard configuration data
are included. These firmware packages are previews, not universal-model firmware.
